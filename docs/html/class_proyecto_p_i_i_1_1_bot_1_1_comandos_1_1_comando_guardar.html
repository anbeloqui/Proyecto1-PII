Detailed Description

Implementa el comando !guardar, encargado de guardar un elemento recomendable para que el usuario pueda verlo después.

Este comando obtiene automáticamente el usuario desde Discord y registra la acción de guardado mediante la Fachada.

No accede directamente al historial, al dominio ni al motor de recomendación.
