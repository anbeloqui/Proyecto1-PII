Enumerator
Consumido 

El usuario consumió el elemento.

El usuario indicó que le gusta el elemento.

Dislike 

El usuario indicó que no le gusta el elemento.

Guardado 

El usuario guardó el elemento para verlo o consumirlo más adelante.
