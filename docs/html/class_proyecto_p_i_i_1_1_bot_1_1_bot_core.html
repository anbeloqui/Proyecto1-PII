Detailed Description

Coordina el registro y la ejecución de los comandos del bot de Discord.

Esta clase actúa como intermediaria entre DiscordBot y los comandos concretos del sistema.

Su responsabilidad consiste en mantener el conjunto de comandos disponibles, identificar cuál corresponde ejecutar a partir del mensaje recibido y delegar la ejecución al objeto adecuado.

No contiene lógica de negocio ni accede directamente al motor de recomendación. Toda funcionalidad específica queda encapsulada en las implementaciones de IComandoDiscord.

Precondiciones:

  • Los comandos registrados deben implementar IComandoDiscord.

Postcondiciones:

  • Cada comando queda asociado a su nombre para futuras ejecuciones.
  • Si un mensaje corresponde a un comando registrado, este será ejecutado.
  • Las excepciones de dominio se informan al usuario sin detener el bot.

Procesa un mensaje recibido desde Discord e intenta ejecutar el comando correspondiente.

Parameters
messageMensaje recibido por el bot.
Returns
Una tarea asincrónica que representa el procesamiento del mensaje.
Exceptions
ArgumentNullExceptionSe lanza cuando message es null.

Precondiciones:

  • message debe ser distinto de null.

Postcondiciones:

  • Si el mensaje proviene de otro bot, no se realiza ninguna acción.
  • Si el comando existe, se delega su ejecución.
  • Si el comando no existe, el método finaliza sin producir cambios.
  • Si ocurre una excepción de dominio, se informa al usuario por Discord.
