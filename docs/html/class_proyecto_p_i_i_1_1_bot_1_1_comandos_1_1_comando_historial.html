Detailed Description

Implementa el comando !historial, encargado de mostrar el historial del usuario que ejecutó el comando.

Este comando obtiene automáticamente el usuario desde Discord y solicita su historial a la Fachada.

No accede directamente al dominio, al motor de recomendación ni a las estructuras internas del historial.

Precondiciones:

  • message debe ser distinto de null.
  • argumentos debe ser distinto de null.

Postcondiciones:

  • El historial se obtiene mediante la Fachada para el usuario identificado por SocketMessage.Author.
  • La respuesta es enviada al canal desde el cual se ejecutó el comando.
